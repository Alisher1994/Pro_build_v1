# Интеграция с Didox API: Структуры JSON (Спецификации)

Для каждого типа документа Didox требует строго определенную структуру JSON.

## 1. Счета-Фактуры (Factura)
Основные поля: `Seller`, `Buyer`, `Products`, `Contract`.
*   **Типы:**
    *   `Обычная ЭСФ`: Стандартный набор полей.
    *   `ФАРМ ЭСФ`: Дополнительная информация о лекарственных средствах.
    *   `Гибридная ЭСФ`: Для специфических случаев расчетов.
    *   `Односторонняя ЭСФ`: Для услуг нерезидентов, чеков и т.д.

## 2. Акты (Act)
*   **Акт выполненных работ:** Перечень работ, объем, цена.
*   **Акт сверки (Reconciliation Act):** Сводная таблица по дебиторской и кредиторской задолженности за период.
*   **Акт приема-передачи (Transfer Act):** Перечень передаваемых ТМЦ.

## 3. ТТН (Товарно-транспортная накладная)
*   **Секции:** Грузоотправитель, Грузополучатель, Перевозчик, Информация о транспорте (госномер, прицеп), Сведения о грузе.

## 4. Доверенности (Power of Attorney)
*   Данные доверенного лица (ПИНФЛ, Паспортные данные).
*   Срок действия.
*   Перечень ТМЦ, которые разрешено получить.

## 5. Договоры (Contract)
*   Номер, дата, предмет договора.
*   Реквизиты сторон (банки, расчетные счета).

## 6. Произвольные документы
*   `JSON + HTML/PDF` шаблон. Позволяет отправлять любые документы в свободной форме с юридической силой подписи.
