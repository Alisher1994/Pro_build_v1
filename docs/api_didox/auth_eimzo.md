# Интеграция с Didox API: Авторизация и E-IMZO

## 1. Авторизация

### Логин по ЭЦП и получение токена
Для выполнения большинства операций требуется токен авторизации (Bearer Token).
*   **Endpoint:** `POST /v1/auth/:taxId/token/:locale`
*   **Описание:** В ответе возвращается токен в формате UUID.
*   **Срок действия:** 360 минут.

### Логин по паролю
*   **Endpoint:** `POST /v1/auth/:taxId/password/:locale`
*   **Описание:** Используется пароль регистрации. Если логин выполняется под ИНН физлица, возвращается список привязанных компаний.

---

## 2. Работа с E-IMZO (ЭЦП)

Процесс подписания происходит на стороне клиента (браузера) с использованием библиотеки E-IMZO.

### Шаги подписания:
1.  **Получение списка ключей:** Вызов метода `listAllUserKeys()` для отображения доступных сертификатов пользователю.
2.  **Выбор ключа и получение keyId:** После выбора ключа получаем его уникальный `keyId`.
3.  **Создание подписи:**
    *   Данные для подписи должны быть в формате Base64.
    *   Создается "отсоединенная" подпись (PKCS#7).
4.  **Добавление Timestamp:** Прикрепление метки времени к созданной подписи для юридической значимости в будущем.

### Логин в компанию под физлицом
*   **Endpoint:** `POST /v1/auth/company/:companyTaxId/login/:locale`
*   **Описание:** Позволяет переключиться на контекст конкретной компании, используя токен физического лица.
