# Документация по интеграции Didox API

Эта папка содержит структурированную информацию для будущей интеграции проекта с системой электронного документооборота **Didox.uz**.

## Содержание
1.  **[Авторизация и E-IMZO](auth_eimzo.md)** — Как получать токены и подписывать данные.
2.  **[Регистрация и Аккаунт](registration_account.md)** — Управление профилем, филиалы, склады и настройки ИКПУ.
3.  **[Работа с документами](documents_api.md)** — Методы создания, отправки, подписания и удаления документов.
4.  **[Спецификации JSON](json_structures.md)** — Форматы данных для ЭСФ, Актов, ТТН и других документов.
5.  **[Справочники и Утилиты](catalogs_utils.md)** — Банки, ЕИ, Регионы, НДС и поиск контрагентов.
6.  **[Публичная оферта и Шаблоны](templates_offer.md)** — Подписание новой оферты и работа с шаблонами договоров.
